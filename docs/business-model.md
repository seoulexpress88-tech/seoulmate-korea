# Seoulmate 수익 모델

일정 설계비로 첫 매출을 만들고, 장기 수익은 일정 안에서 일어나는 예약 수수료, 그리고 블로그로 들어온 검색 트래픽에서 나오는 구조입니다. 리뷰와 추천의 신뢰가 곧 전환율이므로 광고와 추천을 섞지 않습니다.

## 수익원

| 수익원 | 방식 | 가격 예시 | 시기 |
|---|---|---|---|
| 일정 설계비 | 플래너는 무료, 지도·교통·예약 링크가 들어간 전체 일정은 유료 | $12 + $2/일 | 결제 연동 후 |
| 로컬 컨시어지 | 한국인 에디터가 일정 검수, 식당 예약, 여행 중 채팅 지원. 에디터 70% / 플랫폼 30% | $39 + $6/일 | 결제 연동 후 |
| 예약 제휴 수수료 | 블로그 글과 일정 속 투어·KTX·숙소 링크 (Klook 약 2~5%, Trip.com·Agoda 등) | 파트너별 상이 | 글 20개 이후 신청 |
| 디스플레이 광고 | Google AdSense (자체 도메인 + 양질의 글 20~30개 후 신청) | 트래픽 비례 | 글 30개 전후 |
| 여행 필수품 번들 | eSIM, 교통카드, 공항 픽업, 짐 배송 | 건당 마진 | 3개월 |
| 현지 업체 노출 | 식당·공방·댄스 클래스가 "Sponsored" 표시로 후보에 노출, 추천 순위는 그대로 | 월정액 또는 CPA | 6개월 |
| B2B 화이트라벨 | 호텔·게스트하우스·어학당에 자사 브랜드 플래너 제공 | 월 구독 | 12개월 |

## 고객 1명당 매출 예시 (5일 일정, 가정치)

- 일정 설계비 $20
- 투어·입장권 $250 예약 시 제휴 수수료 약 $10~15
- eSIM·교통카드 번들 마진 약 $8
- 합계 약 $40 내외 (컨시어지 제외)

## 리뷰 데이터 원칙

- 지금 플래너는 장소마다 Google Maps·네이버 지도 링크를 달아 실제 여행자 리뷰를 바로 볼 수 있게 했습니다. 지어낸 리뷰는 사이트에 올리지 않습니다.
- 다음 단계: 일정을 이용한 여행자에게 귀국 후 인증 리뷰를 받습니다 (국적, 방문 시기, 여행 유형 표시).
- 외부 리뷰는 Google Places API, Tripadvisor Content API 같은 공식 경로로만 쓰고 출처 표기와 캐싱 기한 등 약관을 지킵니다. 스크래핑은 하지 않습니다.
- 광고·협찬은 "Sponsored"로 표시합니다 (공정위 추천·보증 심사지침).

## 시작 전에 확인할 것

- **호스팅 요금제:** Vercel 무료(Hobby) 요금제는 비상업용입니다. 결제·광고·제휴 수익을 붙이는 시점에는 Vercel Pro(월 $20)로 올리거나, 상업 이용이 가능한 Cloudflare Pages로 옮겨야 합니다. 사이트가 정적 파일이라 이전은 간단합니다.
- **여행업 등록:** 예약을 직접 받거나 대행하면 관광진흥법상 여행업 등록이 필요할 수 있습니다. 제휴 링크 단계와 직접 예약 단계를 나눠 전문가에게 확인하세요.
- **해외 결제:** 외국 카드 결제가 되는 PG(Stripe, PayPal 등)와 환불 규정을 정합니다.
- **중복 콘텐츠:** 같은 글이 Blogger와 이 사이트에 모두 올라가면 구글이 한쪽만 검색에 노출합니다. 이 사이트를 메인으로 하고 Blogger 게시는 중단하는 편이 좋습니다.
