리뷰 데이터: "실제 외국인 리뷰"를 확보하는 방법

1. 자체 인증 리뷰 (핵심)

예약·일정 이용이 확인된 여행자에게만 귀국 후 리뷰를 요청합니다. 국적, 방문 시기, 여행 유형(혼자/커플/가족)을 함께 표시하면 다른 외국인이 판단하기 쉽습니다. 작성 시 다음 여행 할인 쿠폰을 보상으로 줍니다.

2. 공식 API (초기 보완)

Google Places API, Tripadvisor Content API 같은 공식 경로로만 가져옵니다. 출처 표기와 캐싱 기간 제한 같은 이용 약관을 지켜야 하고, 웹 스크래핑은 약관 위반과 법적 분쟁 위험이 있어 쓰지 않습니다.

3. 신뢰 장치

  • 광고 업체도 리뷰·별점 정렬은 동일하게 적용
  • "Sponsored" 라벨 명시 (공정위 추천·보증 심사지침)
  • 업체가 리뷰를 삭제·대가 작성 요청 불가

시작 전에 확인할 것

여행업 등록

일정 판매를 넘어 예약을 직접 받거나 대행하면 관광진흥법상 여행업 등록이 필요할 수 있습니다. 제휴 링크만 쓰는 단계와 직접 예약 단계를 나눠 세무사·행정사와 확인하세요.

해외 결제

외국 카드 결제가 되는 PG(Stripe, PayPal, 국내 PG의 해외카드 결제)와 환불 규정(출발 전 전액 환불 등)을 미리 정합니다.

첫 MVP 범위
