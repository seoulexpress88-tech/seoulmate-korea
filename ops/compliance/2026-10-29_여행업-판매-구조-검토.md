# [규리 · 컴플라이언스 검토] 여행업·판매 구조 (T-0003)

- 작성: 규리(seoulmate-compliance) · 2026-10-29
- 대상: 개인 고단가 상품 2종("Private Day with a Seoul Local", "Custom Korea Trip + Concierge"), 외국인 단체·B2B 맞춤 일정 + 현지 운영 패키지, Stripe/PayPal 결제 링크, Vercel Hobby 호스팅
- 목표 기여: 1억 원 매출 목표를 **법적 위험 없이** 달성할 수 있는 판매 구조를 정해, 판매 개시 후 중단·처벌로 매출이 0이 되는 사태를 막는다.
- 이 문서는 법률 자문이 아니다. "전문가 확인 필요" 항목은 행정사·변호사·세무사 확인 후 확정한다.

## 결론: **수정 후 가능** (현 구조 그대로 직접 판매는 **보류**)

| 상품/행위 | 판정 | 한 줄 이유 |
|---|---|---|
| 일정 설계·정보만 판매(예약·동행 없음) | **진행 가능**(조건부) | 여행업 정의(알선·대리·안내·편의 제공) 밖에 두려면 "정보 상품"으로 한정해야 함. 경계 해석은 전문가 확인 |
| 식당·체험·숙박 **예약 대행**(Concierge) | **보류 → 제휴 여행사 통해 가능** | "시설 이용 알선·계약 체결의 대리" = 여행업. 외국인 대상이면 **종합여행업** 등록 필요 |
| **현지인 1일 동행**(Private Day) | **보류 → 제휴 여행사 + 자격 가이드로 가능** | "여행에 관한 안내" = 여행업. 외국인 대상 여행업자는 **관광통역안내사 자격자**를 안내에 종사시켜야 함 |
| 숙박·교통·식사 수배 포함 **단체·B2B 패키지** | **보류 → 제휴 여행사(랜드사)가 계약 당사자일 때 가능** | 전형적 여행업. 보증보험·여행계약서·안전정보 제공 의무까지 따름 |
| Stripe/PayPal 결제 링크로 직접 수금 | **수정 후 가능** | Stripe는 한국 사업자 가입 불가. 결제 주체 = 계약 당사자여야 함(제휴 구조면 여행사가 수금) |
| Vercel Hobby에서 판매·결제 유도 | **수정 후 가능** | Hobby는 비상업 전용. 판매 시작 **전에** Pro 전환 필요(돈 드는 일 → 대표 승인) |

## 1. 관광진흥법상 여행업 등록이 필요한 범위

### 1-1. 근거 조문 (국가법령정보센터 law.go.kr, 2026-10-29 조회)
- **관광진흥법** [시행 2026.10.29.] [법률 제21584호]
  - 제3조 제1항 제1호(여행업): 여행자 또는 운송·숙박시설, 그 밖에 여행에 딸리는 시설의 경영자 등을 위하여 **그 시설 이용 알선이나 계약 체결의 대리, 여행에 관한 안내, 그 밖의 여행 편의를 제공하는 업**
  - 제4조 제1항: 여행업을 경영하려는 자는 특별자치시장·특별자치도지사·시장·군수·**구청장에게 등록**하여야 한다.
  - 제9조: 관광사업자는 보험·공제 가입 또는 영업보증금 예치 의무
  - 제14조: 여행계약 시 안전정보 서면 제공, 여행계약서(일정표·약관 포함)와 보험 가입 증명서류 교부, 일정 변경 시 사전 동의
  - 제82조 제1호: **등록 없이 여행업을 경영한 자 → 3년 이하 징역 또는 3천만원 이하 벌금**(병과 가능)
- **관광진흥법 시행령** [시행 2026.10.29.] [대통령령 제36772호] 제2조 제1항 제1호(여행업 종류)
  - 가. **종합여행업: 국내외를 여행하는 내국인 및 외국인을 대상**으로 하는 여행업(사증 대행 포함)
  - 나. 국내외여행업: 국내외를 여행하는 **내국인** 대상
  - 다. 국내여행업: 국내를 여행하는 **내국인** 대상
  - → **외국인 고객을 받으려면 '종합여행업'만 해당**. 국내여행업·국내외여행업으로는 외국인 대상 영업 불가.

### 1-2. 행위별 판단

| 행위 | 여행업 해당 여부 | 근거·설명 | 위험도 |
|---|---|---|---|
| ① 일정 설계·정보 판매(PDF 일정표, 추천 리스트, 화상 상담) — 예약·결제 대리·현장 동행 없음 | **원칙적으로 비해당 가능성이 큼** | 정의의 핵심 행위(알선·대리·안내) 없이 정보 콘텐츠·컨설팅을 파는 구조. 단, "그 밖의 여행 편의를 제공"이 넓게 해석될 여지, "여행에 관한 안내"를 비대면 상담까지 포함하는지 유권해석 미확인 | 보통 · **전문가 확인 필요** |
| ② 예약 대행(식당·체험·공연·숙박 예약을 고객 대신 진행, 예약금 대납) | **해당** | "시설 이용 알선이나 계약 체결의 대리" 문언에 직접 해당. 식당·체험도 "여행에 딸리는 시설"로 볼 가능성 높음 | **높음** |
| ③ 현지 동행(유료 1일 동행·가이드) | **해당** | "여행에 관한 안내". 외국인 대상이므로 종합여행업 + 관광통역안내사(제38조, 아래 4장) | **높음** |
| ④ 숙박·교통·식사 수배 포함 패키지(개인·단체·B2B) | **해당** | 알선·대리·안내·편의 제공 전부 포함. 보증보험·여행계약서·안전정보 의무 | **높음** |
| ⑤ 여행 중 채팅 지원(정보 응답만) | 정보 응답만이면 ①과 같음. 채팅 중 예약 대행하면 ② | 상품 설명에서 "예약 대행"을 빼거나 제휴 여행사로 넘겨야 함 | 보통 |

> 참고: 제주자치경찰단이 무등록 여행업(34개월, 약 1,200건·38억 원)을 검찰 송치한 사례가 보도됨(뉴스서울, 2024~2025 보도). 외국인 대상 무등록 영업은 실제 단속 대상이다.

## 2. 종합여행업 등록 요건과 소요 기간

### 2-1. 요건 (공식 출처)
| 항목 | 기준 | 출처 |
|---|---|---|
| 자본금 | **5천만원 이상** (개인은 사업에 제공되는 **자산평가액**) | 관광진흥법 시행령 [별표 1] <개정 2026.8.4.> (law.go.kr 별표 파일, 2026-10-29 조회) |
| 사무실 | 소유권이나 사용권이 있을 것 | 같은 별표 |
| 보증보험(또는 공제·영업보증금) | 사업 시작 **전** 가입·유지. 금액은 직전 사업연도 매출액 기준 [별표 3]: 종합여행업 매출 1억 미만 **5,000만원**, 1억~5억 6,500만원, 5억~10억 8,500만원, 10억~50억 1억 5,000만원 (단위 천원 표기) | 관광진흥법 시행규칙 [시행 2026.10.29.] [문체부령 제650호] 제18조, [별표 3] <개정 2021.9.24.> |
| 신규 사업자 | 직전 매출이 없으면 "1억 미만" 구간 금액 적용(별표 3 비고) | 같은 별표 비고 3 |
| 기획여행 추가 보증 | 기획여행(법 제2조 제3호: **국외여행**자 대상)을 실시할 때 추가 가입(1억 미만 2억원). 외국인 **방한(인바운드)** 패키지가 여기에 해당하는지는 문언상 비해당으로 보이나 확인 필요 | 시행규칙 제18조 ②, 별표 3 · **전문가 확인 필요** |
| 등록 기관 | 사무실 소재지 구청(서울 자치구 관광 담당 부서) | 법 제4조 ① |

- 국내여행업(1,500만원)으로는 외국인 대상 불가. 별표 1의 국내여행업 750만원 한시 특례는 2026.6.30.로 **종료**.
- 대표의 식당을 여행업 사무실로 겸용할 수 있는지(사용권·구획 요건)는 구청 실무 판단 사항 → **행정사 확인 필요**.

### 2-2. 소요 기간 (추정)
- 공식 처리기간은 이번 조사에서 확인하지 못했다(미확인).
- 실무상: 자산평가 자료 준비 → 보증보험 가입(보증보험사 심사) → 등록 신청 → 등록증 → 사업자등록 업종 추가 → 통신판매업 신고 순. **대략 2~4주로 추정**(행정사 블로그 등 2차 자료 기준, 공식 아님).
- 등록 후에도 외국인 동행 상품은 **관광통역안내사 자격자 확보**가 별도로 필요하고, 자격 시험은 연 단위라 이번 달 안에 직접 취득은 불가능.
- → **이번 달(~11/28) 매출 목표 기간 안에 직접 등록 + 운영 체계를 갖추기는 빠듯함.** 단기에는 제휴 구조가 현실적.

## 3. 빠른 대안: 등록 여행사(종합여행업)와 제휴

### 3-1. 권장 구조 — "Seoulmate = 기획·마케팅 채널, 여행사 = 계약·수금·운영 당사자"
1. 고객 계약 당사자는 **제휴 종합여행사**. 상품 페이지에 "Operated by ○○ Travel (종합여행업 등록번호 ○○구 제○○호)" 명시.
2. 결제는 **여행사 명의 결제 링크**로 받는다. Seoulmate가 대금을 먼저 받아 넘기면 "계약 체결 대리·알선"으로 볼 위험.
3. 여행사가 여행계약서·약관·안전정보·보증보험 증명서를 고객에게 교부(법 제14조).
4. 현지 동행은 여행사 소속(또는 위촉) **관광통역안내사 자격자**가 수행. "Seoul Local"이라는 콘셉트는 유지하되, 자격 가이드가 안내하고 현지인은 동반(비안내) 역할로 정리.
5. Seoulmate는 일정 설계·콘텐츠·마케팅 대가로 **여행사로부터 수수료/용역비**를 받는다(세금계산서). 
6. 일정 설계(정보 상품)만은 Seoulmate가 직접 판매 가능(1-2 ①, 단 전문가 확인).

### 3-2. 주의점
| 주의점 | 위험도 | 설명 |
|---|---|---|
| 명의만 빌리는 구조 금지 | **높음** | 실제로 Seoulmate가 수금·수배·운영하고 여행사는 이름만 빌려주는 형태는 무등록 영업(제82조)으로 볼 수 있음. 실질 운영·책임이 여행사에 있어야 함 |
| 통신판매중개자 고지 | 보통 | Seoulmate가 판매 페이지만 중개하면 "자신이 통신판매의 당사자가 아니라는 사실"을 미리 고지해야 함. 안 하면 여행사 과실 손해에 **연대 배상**(전자상거래법 제20조 ①, 제20조의2 ①, [시행 2026.7.21.] 법률 제21312호) |
| 매출 인식 | 보통 | 제휴 구조에서 Seoulmate 매출은 **수수료·용역비만**. 1억 원 목표 계산 시 여행사 수금액 전체를 Seoulmate 매출로 기록하면 안 됨(CLAUDE.md: 실제 매출만 기록) → 한결 공유 필요 |
| 제휴 계약서 | 보통 | 책임 분담(사고·환불·분쟁), 수수료율, 개인정보 위탁/제공, 브랜드 사용, 해지 조항. **변호사 검토 권장** |
| 여행사 확인 | 낮음 | 종합여행업 등록 여부, 보증보험 유효 여부를 등록증·증권으로 확인 |
| 광고 표기 | 낮음 | 제휴 상품임을 표시(공정위 추천·보증 심사지침 — 기존 Affiliate disclosure 페이지에 반영) |

## 4. 관광통역안내사 자격 (현지인 동행 상품 영향)

- **관광진흥법 제38조**(law.go.kr, 2026-10-29 조회)
  - ① 단서: "외국인 관광객을 대상으로 하는 여행업자는 **관광통역안내의 자격을 가진 사람을 관광안내에 종사하게 하여야** 한다."
  - ⑥: 관광통역안내 자격이 없는 사람은 외국인 관광객 대상 관광안내(외국인 대상 여행업에 종사하여 안내하는 경우)를 하여서는 아니 된다.
  - ⑦: 자격자가 안내할 때 자격증 패용 의무.
- **제86조** ①: 제38조 ⑥ 위반(무자격 관광통역안내) → **500만원 이하 과태료**. ②: 자격증 미패용 → 100만원 이하 과태료.
  - 차수별 금액(1차 150만·2차 300만·3차 500만원)은 언론 보도 기준(세계일보 2023-10-29) — 시행령 과태료 별표로 최종 확인 필요.
  - 무자격 가이드를 쓴 여행업자는 시정명령·과징금·사업정지·등록취소 등 행정처분 대상(문체부 점검 보도).
- **영향**: "Private Day with a Seoul Local"을 **자격 없는 현지인이 유료로 안내**하면 (a) 여행사 없이 하면 무등록 여행업(형사), (b) 여행사 통해 해도 무자격 안내(과태료·행정처분). → **자격 가이드 동행이 필수 조건**. 상품명·설명에서 "Local friend"로 포장해도 실질이 유료 관광안내면 동일하게 판단될 위험.
- 대안: ① 제휴 여행사의 자격 가이드 배정, ② 동행 없이 "맞춤 일정 + 원격 채팅 정보 지원"으로 상품 축소.

## 5. 해외 고객 결제·환불

### 5-1. 결제 수단
| 항목 | 확인 내용 | 판단 |
|---|---|---|
| Stripe | 공식 지원국 목록에 **대한민국 없음**(stripe.com/global, 2026-10-29 조회) → 한국 개인사업자 명의 가입 불가 | 해외 법인 없이 사용 불가. **사용하지 말 것**(타인·해외 명의 우회 금지) |
| PayPal | 한국 사업자 계정 개설 가능. 다만 여행 서비스에 대한 이용정책(사전승인 여부) 원문은 이번 조회에서 열람 실패 | **PayPal 이용목적 제한 정책 확인 필요** |
| 제휴 구조 | 여행사 결제 링크 사용 | 권장 |

### 5-2. 청약철회 (전자상거래법)
- **전자상거래 등에서의 소비자보호에 관한 법률** [시행 2026.7.21.] [법률 제21312호] (law.go.kr, 2026-10-29 조회)
  - 제17조 ①: 계약내용 서면을 받은 날부터 **7일** 이내 청약철회 가능(공급이 늦으면 공급 개시일부터 7일).
  - 제17조 ② 제5호: **용역 제공이 개시된 경우** 철회 제한(가분적 용역은 미개시 부분 철회 가능). 단, 같은 조 ⑥에 따라 철회 제한 사실을 **소비자가 쉽게 알 수 있게 표시**하지 않으면 제한을 주장할 수 없음.
  - 제17조 ③: 표시·광고와 다르거나 계약과 다르게 이행되면 공급일부터 3개월, 안 날부터 30일 이내 철회 가능.
  - 제12조: 통신판매업 신고 의무(Seoulmate가 직접 정보 상품을 팔면 대상).
- 일정 설계(디지털 콘텐츠)는 제공 개시 후 철회 제한 가능하나, 결제 전 "제공 개시 후 환불 불가" 고지 + 견본·범위 표시 필요.
- 해외 소비자는 거주국 소비자보호법도 주장할 수 있음(국제사법상 소비자계약 특칙) → 환불 규정을 한국 기준보다 불리하게 쓰지 말 것. **변호사 확인 권장**(보통).

### 5-3. 여행 취소 수수료 기준
- 공식 기준: **소비자분쟁해결기준**(공정거래위원회 고시 제2025-14호, 시행 2025.12.18., law.go.kr 조회) 여행업 항목 + 공정위 국내·국외여행 표준약관. 고시 본문 별표는 이번 조회에서 원문 수치 확인을 못 해, 아래 수치는 **2차 자료**다.
- 방한 외국인 상품은 "국내 여행"이므로 **국내여행 표준약관** 체계가 가까움(여행자 귀책 출발 전 해제, 여행사 공개 약관 기준):
  | 통보 시점 | 수수료 |
  |---|---|
  | 당일여행 3일 전 / 숙박여행 5일 전까지 | 전액 환급 |
  | 2일 전 | 요금의 10% |
  | 1일 전 | 요금의 20% |
  | 당일 통보·불참 | 요금의 30% |
  (출처: 투어비스 국내여행 표준약관 공개 페이지, 2026-10-29 조회 — 공식 원문 대조 필요)
- 참고(국외여행 표준약관, 2차 자료): 30일 전 계약금 환급 / 20일 전 10% / 10일 전 15% / 8일 전 20% / 1일 전 30% / 당일 50%.
- 단체·B2B는 사업자 간 계약이라 소비자법 대신 계약서로 정하되, 예약금(식당·체험 위약금) 실비 반영 조항을 넣는다.
- **제휴 구조에서는 여행사 약관이 적용**되므로, Seoulmate 상품 페이지 문구가 여행사 약관과 다르지 않게 맞춘다.

## 6. Vercel Hobby 상업 이용 제한

- 출처: Vercel Docs "Fair Use Guidelines" > Commercial usage (vercel.com/docs/limits/fair-use-guidelines, last_updated 2026-09-14, 2026-10-29 조회)
  - "Hobby teams are restricted to non-commercial personal use only." 상업 이용은 Pro 또는 Enterprise 필요.
  - 상업 이용 예시: **방문자에게 결제를 요청·처리하는 모든 방법**, **상품·서비스 판매 광고**, 사이트 제작 대가 수령, 제휴 링크가 사이트의 주목적인 경우, 광고(AdSense 등) 게재. 기부 요청은 예외.
- 판단: 상품 판매 페이지·결제 링크·"Book now"를 올리는 순간 **상업 이용** → **판매 개시 전에 Pro 전환 필요**. 결제를 외부 링크(여행사 결제창)로 넘겨도 "서비스 판매 광고"에 해당하므로 동일.
- 위험도: **높음**(계정·배포 일시정지 시 사이트 전체 중단). Pro 전환은 돈이 드는 일·계정 설정 변경 → **대표 승인 필요**. 요금은 vercel.com/pricing에서 확인(이번 검토에서 금액 미확인).

## 8. 수정안 (담당자에게 전달)

1. **서아(기획)**: 상품을 두 갈래로 재설계
   - A. Seoulmate 직접 판매: "Custom Korea Itinerary"(일정 설계 PDF + 출발 전 화상 상담 + 여행 중 **정보** 채팅). 예약 대행·동행·대금 대납 문구 삭제.
   - B. 제휴 여행사 운영: "Private Day"(자격 가이드 동행), "Concierge 예약 대행", 단체·B2B 패키지. 계약·결제·약관은 여행사.
2. **지후(리서치)**: 서울 소재 **종합여행업** 등록 여행사(인바운드 전문, 영어 자격 가이드 보유) 후보 3~5곳 조사 — 등록번호, 보증보험, 수수료 관행. (외부 연락은 승인 후)
3. **도윤(개발)**: Pro 전환 승인 전까지 결제·"Book" 버튼 배포 금지. 승인 후 상품 페이지에 운영사 표기·중개자 고지·환불 규정·청약철회 제한 고지 영역 마련.
4. **나래(마케터)**: "local friend가 안내" 류 표현 금지 → "licensed English-speaking guide + local host" 등 실제 구조대로. 제휴 표기.
5. **한결(총괄)**: 승인 요청에 포함 — (a) Vercel Pro 전환(비용), (b) 제휴 여행사 접촉, (c) 약관·환불·개인정보처리방침 변경, (d) 장기적으로 직접 종합여행업 등록 여부(자본 5천만원·보증보험 5천만원·사무실).
