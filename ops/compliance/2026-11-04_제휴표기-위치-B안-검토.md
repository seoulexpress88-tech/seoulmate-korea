# [규리 · 컴플라이언스 검토] 제휴 표기 위치 B안 (worktree seoulmate-wt-affnotice, 브랜치 aff-notice-b, 커밋 a04a716)

검토일: 2026-11-04 · 대상: build.py(AFF_NOTE/AFF_LINE, page_city/page_post/page_planner), static/style.css(.aff-note/.aff-line)
기여: 표기 위험을 줄이면 사이트 신뢰도가 올라가 지금의 수익원(광고·제휴)과 방문자 늘리기에 도움이 된다.

## 결론: 수정 후 가능 (작은 수정 2가지)

## 확인한 근거
- 공정위「추천·보증 등에 관한 표시·광고 심사지침」(예규 제473호, 2024-11-13 개정, 2024-12-01 시행). 이번에 바뀐 점: 문자 중심 게시물은 표시 문구를 **제목이나 첫 부분**에 둬야 함(끝부분만 표시하는 것은 더 이상 안 됨). 첫 부분 문구는 **본문보다 글자를 크게 하거나 글자색을 다르게** 해서 쉽게 알아보게 해야 함. 구매 링크로 나중에 수수료를 받는 경우도 표시 대상. "수수료를 받을 수 있음" 같은 조건부 표현은 불명확한 예시로 들어감. (법무법인 세종 뉴스레터 및 언론 보도로 확인. 예규 원문은 이번에 직접 대조하지 못함)
- 미국 FTC Guides Concerning the Use of Endorsements and Testimonials (16 CFR Part 255, 2023-06 개정): 표시는 clear and conspicuous여야 함. 시각 표시는 크기·대비·위치로 "놓치기 어려워야" 하고, 링크 가까이, 클릭 전에 보여야 함. FTC ".com Disclosures" 안내도 같은 취지.
- 색 대비(직접 계산): #58646E / 흰색 6.06:1, / #F4F6F3 5.58:1. 다크 #98A6B0 / #17202A 6.59:1. 모두 WCAG AA(4.5:1) 이상이라 읽기 어려운 수준은 아님.
- 빌드 결과 확인: 도시 페이지 14곳·플래너는 Book ahead 박스 안에서 제목 → aff-note → 링크 순서. 링크마다 'affiliate link' 라벨과 rel="sponsored" 있음. 가이드 38편 중 6편은 본문 링크가 있어 제목 바로 아래 aff-line이 첫 문단보다 앞에 나옴. 32편은 Book ahead 박스만 있어 위쪽 문구가 없음.

## 최소 수정안 (도윤에게 전달, 승인 후 반영)
1. **가이드는 제휴 링크가 하나라도 있으면 제목 아래 한 줄을 넣는다** (Book ahead 박스만 있는 32편 포함). page_post에서 `aff_top = AFF_LINE if inline_aff else ""`를 `aff_top = AFF_LINE if used_aff else ""`로 바꾼다. 박스만 있는 글에 맞게 문구를 나누는 것도 가능: 본문 링크가 있으면 지금 문구 그대로, 박스만 있으면
   "This guide includes affiliate links (see "Book ahead"): Seoulmate earns a commission if you book through them. Learn more"
   한 줄 회색이고 배경 박스가 없어서, 대표가 싫다고 한 노란 박스 문제는 생기지 않음.
2. **앞머리만 진하게**: aff-line과 aff-note 둘 다 문장 앞에 `<b>Affiliate links:</b>`를 붙이고, CSS에 `.aff-line b,.aff-note b{color:var(--ink);font-weight:700}`를 추가한다(링크 라벨과 맞추려면 var(--warn)도 괜찮음. #9A5B00/흰색 약 5.6:1). 글자 크기 0.85rem과 회색 본문은 그대로 둔다. 이렇게 하면 "글자색을 달리해 쉽게 알아봄" 요건과 FTC의 "놓치기 어려움" 요건을 둘 다 채운다.
   예) `<p class="aff-line"><b>Affiliate links:</b> This guide contains labeled affiliate links: ...`
   (이 경우 문장 안의 "affiliate links"가 겹치므로 "This guide contains labeled links that earn Seoulmate a commission if you book through them."처럼 다듬어도 됨)
- 그대로 둘 것: 링크마다 붙는 'affiliate link' 라벨, rel="sponsored", 글 하단 disclosure 줄, /disclosure/ 페이지.

## 전문가 확인 필요
- 없음(위험도 높음 항목 없음). 다만 공정위 지침이 영어로 된 외국인 대상 페이지에 어디까지 적용되는지, 그리고 'Book ahead' 같은 일반 예약 링크 박스를 "추천·보증"으로 볼지는 해석이 갈릴 수 있음. 그래서 보수적으로 수정안 1을 권함.
- 고지 문구 변경이므로 반영과 발행은 대표 승인을 받아야 함(승인 요청 시 위험도 low).
