# 가이드 공급 공식 채널 + 관광통역안내사 자격 확인 방법 (T-0035)

- 작성: 지후(research) · 2026-11-02 · 공개 자료만. 기관·플랫폼의 **공식 URL과 창구 유형만** 적었다. 개인 이름·전화·이메일은 수집하지 않았다. 연락·가입·폼 제출 없음.
- 신뢰도: 확인됨 / 일부 확인 / 미확인
- 목표 기여: 서아의 창립 가이드 10명(트랙 R 감수자) 모집에 쓸 공식 채널과 자격 확인 절차를 정리해, 승인 후 바로 모집을 시작할 수 있게 한다.

## 결론
1. **공식 채널은 2곳이 핵심이다**: 한국관광통역안내사협회(KOTGA, 일자리정보 게시판·교육·일자리박람회)와 한국관광공사 관광전문인력포털 "관광in"(자격증 발급·구인구직). 둘 다 공식 창구로 공지 게시를 요청하는 방식이다. 모두 외부 연락이므로 **채널별 대표 승인**이 필요하다.
2. **모집 적기는 12월 중순 이후다.** 제26회(2026) 면접 합격 발표가 2026-12-16부터다(Q-Net). 서아 플랜 1순위인 "최근 자격 취득자"가 이때 새로 나온다.
3. **자격을 제3자가 공개 조회하는 시스템은 찾지 못했다.** 확인 가능한 경로는 (a) 본인이 관광in에 로그인해 "나의 자격증 보유현황"을 보여 주는 방식, (b) Q-Net "확인서 발급 → 진위여부확인" 메뉴다. (b)는 확인서 종류와 제3자 사용 가능 여부가 미확인이다.

**시사점**: 해외 플랫폼은 "공개 신청 + 인터뷰 + 엄격한 승인"이 표준이다. 서아 플랜(신청 → 서류 → 화상 인터뷰 → 협약)과 같은 구조라 그대로 가도 된다. 우리 차별점은 **창립 85% 수령**(업계 20~30% 수수료 대비)과 **이름이 실리는 감수 글**이다.

## 2. 관광통역안내사 자격 확인 방법

| 방법 | 공식 경로 | 누가 하나 | 무엇을 확인 | 신뢰도 |
|---|---|---|---|---|
| **A. 관광in "나의 자격증 보유현황"** | https://academy.visitkorea.or.kr → 로그인 → 자격증발급 → 나의 자격증 보유현황 (FAQ: https://academy.visitkorea.or.kr/license/re/licenseFaq.do) | **가이드 본인**이 로그인해 화면 공유 | 자격증 번호, 합격일자 등 보유 정보 | 확인됨(FAQ) |
| **B. Q-Net 확인서 + 진위여부확인** | https://www.q-net.or.kr/man001.do?gId=37&gSite=L → 확인서발급(발급안내·발급신청·발급내역·**진위여부확인**) | 가이드가 확인서 발급 → 우리가 진위여부확인 메뉴로 검증 (가능성) | 시험 합격 관련 확인서로 추정. **확인서 종류, 제3자 진위확인 가능 여부 미확인** | 메뉴 확인됨 / 용도 미확인 |
| **C. 실물 자격증 원본** | 한국관광공사 발급(신규 8,990원, 재발급 6,990원, 온라인 신청만) | 화상 인터뷰에서 원본 제시 | 신형 자격증은 IC칩과 뒷면 개인별 식별코드가 있다. 관광경찰은 공사 DB와 대조해 진위를 확인(FAQ). 민간 업체용 대조 절차는 FAQ에 없음 | 확인됨 |

**제안 (서아 플랜 5-1 ②·③ 보완)**
- ② 서류 확인: 자격증 사본(식별번호 가림)에 더해 **A(보유현황 화면) 또는 B(Q-Net 확인서)** 중 하나를 받는다.
- ③ 화상 인터뷰: 원본 제시 + 관광in 보유현황 화면을 본인이 띄워 보여 준다. 녹화·저장하지 않고 "확인함·일자·확인자"만 기록(현 플랜 유지).
- B 방식이 제3자 확인에 쓸 수 있는지는 Q-Net 발급안내 페이지를 다시 읽거나, 대표 승인 후 공식 문의로 확인 [CHECK].
