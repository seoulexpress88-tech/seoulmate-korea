# [지후 · 리서치 보고] 제휴 여행사·전문가 후보 (T-0011)

- 작성: 지후(seoulmate-research) · 2026-10-30 · 모든 출처 조회일 **2026-10-30**
- 배경: A-0003(등록 종합여행사 제휴로 즉시 판매 + 직접 등록 준비), A-0005(행정사·세무사 상담) 승인. 규리 검토서 `ops/compliance/2026-10-29_여행업-판매-구조-검토.md` 후속.
- 목표 기여: 제휴 여행사 후보를 좁혀 1억 원 목표 기간 안에 **합법적으로 판매를 시작할 수 있는 운영사**를 확보하고, 직접 등록 일정을 공식 기준으로 계산할 수 있게 한다.
- **어디에도 연락하지 않았다.** 아래 문의 채널은 대표 승인 후 사용할 회사 공식 채널이다. 개인 휴대전화·개인 이메일은 일부러 적지 않았다.
- 표기: **확인**(공식 서식·관공서·회사 공식 사이트 표기), **일부 확인**(회사 자기 표기만 있고 관공서 대조 못 함), **미확인**.

## 결론 (한 줄씩)
1. **제휴 1순위 후보는 VIP Travel, Korea Tour Company, KoreaTravelEasy**(모두 서울, 프라이빗·맞춤 투어 운영, 소~중규모). Trazy는 제휴(어필리에이트) 프로그램이 이미 공개돼 있어 **계약 협상 없이 바로 쓸 수 있는 보조 경로**.
2. 10곳 모두 **종합여행업 등록 여부를 관공서 자료로 대조하지는 못했다**(일부 확인). 회사 사이트에 관광사업 등록번호를 표기한 곳은 Trazy·Korea Tour Company·KoreaTravelEasy·하나투어ITC 4곳. **접촉 시 등록증·보증보험 증권 사본 요청이 필수**.
3. 여행업 등록 **공식 처리기간은 7일**(관광진흥법 시행규칙 별지 제1호서식, 수수료 3만원). 단, 강남구 안내는 **결격사유 조회 최대 14일 + 현장 실사**가 절차에 들어가 있어, 실무상 서류 완비 후 **2~3주**를 잡는 것이 안전하다(보증보험 가입·자산평가 준비 기간 별도).
4. 전문가 후보: 행정사 4곳(올림·스마트행·이미코리아·피엘), 세무사 4곳(세무법인 가치·세림세무법인·세무법인 이음·한경세무회계). 공개 비용은 **모두 미공개**(상담 무료 표기만 일부).

### 1-2. 추천 이유
- **A1 VIP Travel**: 법인, 서울 도심, 이미 "Custom Tours"(전용 가이드·기사·비즈니스·MICE·의료)와 **공개 파트너십 문의 창구**가 있어 "Seoulmate 기획 → 여행사 운영·수금" 구조와 가장 잘 맞음. 단, 관광사업 등록번호가 사이트에 없으므로 등록증 확인이 첫 조건.
- **A2 Korea Tour Company**: 상품 자체가 **맞춤 프라이빗 투어 중심**이고 등록번호를 공개. 규모가 작아 협상 여지가 클 것으로 보임(추정). 개인사업자로 보이므로 보증보험 금액·한도와 가이드 자격 보유 인원 확인 필요.
- **A3 KoreaTravelEasy**: 2026년 신규 등록(#2026-000001)으로 보이는 작은 법인이고 **Become a Partner** 창구가 있음. 신생이라 제휴에 열려 있을 가능성(추정). 대신 운영 이력이 짧은 것은 위험 요소.
- **B1 Trazy**: 등록번호 공개, 서울 중구. **어필리에이트(최대 4%)는 승인 즉시 쓸 수 있는 합법적 수수료 매출 경로**(계약 당사자·수금 = Trazy). 단가가 낮아 1억 원 목표에는 보조 수단. 별도로 Partnership 폼을 통해 공동 상품 협의 가능.
- **B2 코스모진**: 업력 있는 외국인 전문 법인, 상품 가격 공개, DMC·MICE·VIP 의전 → **B2B·단체 패키지 운영사 후보**로 적합.
- **B3 하나투어ITC**: 종로구청 등록 공개, 인바운드 대형 계열사. 개인 맞춤보다는 단체·B2B 후보. 소규모 파트너십 수용 여부는 미확인.
- **B4 This is Korea Tours**: 맞춤 프라이빗 특화로 상품 적합도는 높지만 **사업자 정보 비공개** → 등록 확인 전엔 후순위.
- **C1~C3**: 등록번호 미표기·고객층 상이(미군)·서울 밖 소재로 후순위.

### 1-3. 공통 확인 사항 (접촉 승인 후 요청할 것)
1. 관광사업 등록증 사본: 업종이 **종합여행업**인지(외국인 대상은 종합여행업만 가능 — 규리 검토 1-1), 관할 구청
2. 보증보험(또는 공제) 증권: 유효기간·금액
3. 영어 **관광통역안내사** 자격자 보유 수 — 모든 후보가 "licensed guide"라고 스스로 적었지만 자격 종류(관광통역안내사인지, 국외여행인솔자인지)는 **미확인**
4. 제휴 형태: 수수료율 또는 net rate, 결제 링크 명의(여행사), 여행계약서·약관 교부 주체, 사고·환불 책임
5. 공식 대조: 행정안전부·지자체 공공데이터(예: 공공데이터포털 "서울특별시 종로구_일반여행업 인허가 정보" https://www.data.go.kr/data/15141513/fileData.do — 항목: 인허가일자·영업상태)로 영업상태 확인 가능. 이번에는 파일 내려받기·API 키가 필요해 대조하지 않음(**미확인**).

## 확인 못 한 것
- 10개 여행사의 **종합여행업** 여부(업종 종류)와 보증보험 유효 여부 — 사이트에 업종 종류를 적은 곳이 없음
- 각 사 관광통역안내사(영어) 자격자 보유 여부·인원
- 파트너 수수료율·net rate (Trazy 어필리에이트 최대 4%만 공개)
- 행정사·세무사 수임료(전부 미공개), 행정사 등록번호
- 세무법인 이음 소재지·공식 사이트, 한경세무회계 페이지 원문(403)
- 강남구 외 서울 자치구의 여행업 등록 담당 부서·실사 여부
- 공공데이터(인허가 정보)로 업체 영업상태 대조 — 파일 다운로드/API 키 필요해 미실시

## 제안
1. 한결 → 대표 승인 범위(A-0003) 안에서 **A1~A3 + Trazy 파트너십 폼**부터 문의. 첫 메일에 1-3의 확인 서류 5종 요청을 넣는다(외부 연락은 대표 승인 확인 후 진행).
2. 행정사 상담은 **올림(서울·처리 속도 사례)** 과 **피엘(인바운드 사업계획서 보완 이슈를 짚음)** 두 곳 견적 비교 권장. 대표 사업장 주소와 식당 공간 겸용 가능 여부를 첫 질문으로.
3. 세무 상담은 **세무법인 가치**(총액/순액·영세율·가이드 원천세를 모두 명시) 우선, 세림세무법인을 비교 견적으로.
4. 등록 여부 최종 대조가 필요하면 공공데이터포털 인허가 데이터(무료) 내려받기를 대표에게 요청(파일 다운로드는 승인 사항).
