# 가이드 모집 플랜 + 프로필 양식 + 감수 협업 운영안 (T-0034)

> **그래서 무엇을 하자는 것인가**
> 1) 가이드를 **"감수자"로 먼저** 모은다. 매칭은 그다음이다. 감수(글 사실 확인)는 콘텐츠 작업이라 여행업 판단(T-0024)과 떼어 낼 수 있을 가능성이 높다 [규리 확인 필요]. 그러면 T-0024가 12월까지 걸려도 모집·프로필·감수 글을 멈추지 않는다.
> 2) 3단계로 간다. **창립 10명(서울) → 감수 글 10편 → 수동 매칭 시범(요청 20, 매칭 5).** 각 단계에 완료 기준을 두고, 기준을 넘어야 다음 단계로 간다.
> 3) 매칭 시범은 **T-0024 결론 전에는 결제도 연결도 하지 않는다.** H6(요청 접수만으로 영업 개시인가)과 R11(가이드 개인의 무등록 여행업 위험) 때문에 "결제 없이 연결만"도 안전하다고 볼 수 없다.
>
> 목표 기여: 미션의 "직접 즐길 수 있게"를 실현할 공급(자격 가이드)을 확보한다. 동시에 감수 글로 신뢰·검색 순위를 올려 ①광고 트래픽을 키운다. ②매칭 수수료의 전제 조건이다. 북극성("월간 완성된 여행 계획 수")에는 가이드가 플래너를 업무 도구로 쓰면서 기여한다.

## 1. 문제
- **가이드**: 새로 자격을 딴 관광통역안내사나 프리랜서는 고객을 찾을 길이 적다. 영문 포트폴리오도 없다. 해외 플랫폼은 수수료가 20~30%다(수수료 모델 문서 1장).
- **우리**: 트래픽이 거의 없어 가이드에게 보여 줄 "고객 수"가 없다. T-0024 결론(종합여행업 등록 등)은 12월 초~중순으로 추정된다(규리 체크리스트 3장). 그때까지 기다리면 가이드 공급이 0인 채로 2개월을 보낸다.
- **여행자**: 자동 영문화 글만으로는 "이 정보가 지금도 맞나"를 믿기 어렵다. 구글도 경험·전문성 신호를 본다.

## 2. 목표와 성공 지표

| 단계 | 핵심 지표 | 목표 | 기한 (90일 표 기준) |
|---|---|---|---|
| 1 창립 모집 | 자격 확인(②·③)을 통과한 창립 가이드 | **10명** (서울 8명 이상) | 모집 승인 후 4주 |
| 2 감수 글 | 실제 감수를 거쳐 발행한 글 | **10편** | 5~8주 |
| 3 매칭 시범 | 요청 / 매칭(실제 투어 진행) | **요청 20 / 매칭 5** | 8~12주, T-0024 결론 뒤 |
| 공통 | 자격 확인 없이 배지를 단 가이드 | **0명** | 항상 |
| 공통 | 실제 감수 없이 붙은 "Checked by" 표기 | **0건** | 항상 |

보조 지표: 가이드 이탈(3개월 안 탈퇴) 2명 이하, 가이드가 자기 채널에 프로필을 공유한 수 5명 이상, 감수에서 고친 사실 오류 수(많을수록 감수가 쓸모 있다는 증거).

## 3. 하지 않을 것
- T-0024 결론 전: 결제, 여행자 요청을 가이드에게 전달, 가이드 가격 표시, 예약 버튼
- 자격 확인 전 프로필 공개, 무자격자 등록
- "월 ○건 보장" 같은 수요 약속, 가짜 프로필·후기
- 실제로 감수하지 않은 글에 "Checked by" 표기, 자동 발행 글에 일괄 표기
- 가이드에게 쇼핑 커미션·제휴 상품 추천 요구
- 대표 승인 없는 외부 연락·게시 (협회·학원·커뮤니티·개인 모두)

## 4. 사용자 이야기
- As a 새로 자격을 딴 관광통역안내사, I want 영문 프로필과 내 이름이 실린 글을 갖고 싶다, so that 첫 고객에게 보낼 신뢰할 만한 포트폴리오가 생긴다.
- As a 프리랜서 가이드, I want 고객에게 보낼 일정표를 빠르게 만들고 싶다, so that 견적 준비 시간이 줄어든다.
- As a 첫 한국 방문 가족 여행자, I want 자격 가이드가 확인한 일정과 팁을 보고 싶다, so that 아이와 무리 없는 동선을 믿고 따른다.
- As a 운영 담당, I want 감수 기록이 글마다 남길 원한다, so that "Checked by" 표기가 항상 사실이다.

### 5-1. 창립 가이드 10명 (모집 승인 후 4주)
**대상 우선순위**
1. 최근 2년 안 자격 취득자, 여행사 전속이 아닌 프리랜서
2. 특화: 가족(아이 동반) / 커플 / 사진 스냅 / 미식·시장
3. 서울 활동 → 부산·제주는 2차
4. 영어 필수, 일본어·중국어 가능자는 가산 (2단계 일본어판 대비)

**구성 목표 (10명)**
| 특화 | 최소 인원 |
|---|---|
| 가족 | 3 |
| 커플·스냅 | 2 |
| 미식·시장 | 2 |
| 궁궐·역사, K-컬처 등 | 나머지 |
| 영어 외 언어 가능 | 2명 이상 |

**채널 (모두 외부 연락이므로 채널별 대표 승인)**
- 관광통역안내사 교육기관·학원 수료생 안내 (신규 자격자 접점)
- 한국관광통역안내사협회 등 공식 단체 공지 요청
- 가이드 커뮤니티 공개 게시판 (운영 규칙 준수)
- 대표 인맥·식당 네트워크 소개
- 개인 연락처를 수집하거나 개인에게 먼저 연락하지 않는다. 가이드가 신청하게 한다.

**가입 절차 (T-0027 8장 + 트랙 분리)**
| 단계 | 트랙 R (감수자, T-0024와 무관할 가능성) | 트랙 M (매칭, T-0024 결론 뒤) |
|---|---|---|
| ① 신청 | 이름, 이메일, 자격 언어, 자격번호, 자격증 사본(식별번호 가림), 활동 지역, 특화(선택) | 추가 없음 |
| ② 서류 확인 | 3영업일 안 | 동일 기록 사용 |
| ③ 화상 인터뷰 | 원본 화면 확인(녹화·저장 안 함), 언어, 상황 질문. "확인함·일자·확인자"만 기록 | 동일 |
| ④ 프로필·협약 | 공개 프로필 작성(6장), 감수자 협약 동의, 사진 이용 동의 | 가이드 약관·행동 기준 동의 |
| ⑤ 활성 | **감수자 활성**: 감수 요청 받기, 프로필 공개(발행 승인 후) | **매칭 활성**: PG 지급대행 등록(계좌는 PG가 직접), 사업자등록 여부, [CHECK] 판매자 신원정보 |

**완료 기준 (관문 1 → 2)**
- 자격 확인 ②·③ 통과 10명, 위 구성 목표 충족
- 10명 모두 협약·동의서 서명, 프로필 초안 검수 끝
- 프로필 페이지 발행 승인 요청 제출 (발행 자체는 대표 승인 후 도윤)

**미달 시**: 4주에 6명 미만이면 채널·메시지를 고친다(나래). 가이드가 거절한 이유를 3개 이상 모아 공고를 고친다. 인원을 채우려고 기준을 낮추지 않는다.

### 5-2. 감수 글 10편 (W5~W8)
- 운영 방법은 7장.
- 주제 선정: 나래의 검색어 기준 주제(T-0033)와 가이드 특화를 맞춘다. 예: "Seoul with kids in winter"(가족 가이드), "Gwangjang Market food guide"(미식 가이드), "Best photo spots in Seoul for couples"(스냅 가이드).
- 1명당 1~2편. 10명이 고르게 나눠 맡아 모두 이름이 실리게 한다.

**완료 기준 (관문 2 → 3)**
- 감수 기록(7-4장)이 있는 글 10편 발행 (발행 = 대표 승인)
- 가이드 5명 이상이 자기 채널에 글·프로필 공유 (가이드 자발, 우리가 요구하지 않음)
- 감수 글 vs 일반 글 비교 자료(검색 노출·평균 체류) 첫 측정. 분석 도구는 동의 방식 결정(대표 결정 #3, 마스터플랜 8절) 뒤

### 5-3. 수동 매칭 시범 (W8~W12, T-0024 결론 뒤에만)

**법적 전제**
| T-0024 결론 | 시범 방식 |
|---|---|
| 종합여행업 등록 완료 (A안) | 사이트 요청 → 운영팀이 가이드 2~3명에게 전달 → 제안 → 여행자 선택 → **PG 결제**(PG 계약 승인 후) → 투어 후 3영업일 안 85% 지급 |
| "중개만이면 등록 불필요" 서면 해석 (C안) | 위와 같음 + 통신판매중개자 고지, 판매자 신원정보 제공 |
| 결론 없음·등록 진행 중 | **시범 보류.** 요청 접수·전달·결제 모두 하지 않는다. 플래너의 "I'd like a guide" 체크는 지금처럼 데이터를 보내지 않는다 |
| 가이드 개인 판매 구조가 무등록 여행업 위험(R11) | 가이드 직접 판매 방식은 쓰지 않는다 |

- "결제 없이 연결만" 시범은 H6 답이 "영업 개시 아님"일 때만 검토한다. 결제가 없으면 수수료도 없어 매출이 0이고, 매출로 기록하지 않는다.
- 여행자 요청 접수(이메일·일정)는 여행자 개인정보 수집이다. 처리방침 개정 + 대표 승인이 먼저다.

**운영**
- 요청 하나는 맞는 가이드 2~3명에게 보낸다(도시·날짜·특화). 응답 목표: 24시간 안 제안 1건 이상.
- 운영팀이 스프레드시트로 수동 관리한다. 자동화(슈파베이스)는 시범 결과를 본 뒤.
- 퍼널을 모두 기록한다: 플래너 완성 → 가이드 체크 → 요청 제출 → 제안 수신 → 선택 → 결제 → 투어 완료 → 후기.

**완료 기준**
- 요청 20건: 이 중 15건 이상이 24시간 안 제안 1건 이상
- 매칭 5건: 여행자가 선택하고 투어가 실제로 끝난 건
- 분쟁·환불 0건 또는 처리 기록 완비
- **실측값 4개로 마스터플랜 가정 교체**: 세션 대비 요청률, 요청 대비 매칭률, 건당 금액, 가이드 응답 시간

**8주 안에 요청 20건이 안 모이면** 그 자체가 결과다. 트래픽 문제인지, 가이드 체크 화면 문제인지 퍼널로 가려 보고한다. 이때 가이드 모집을 늘리지 않는다.

## 6. 가이드에게 트래픽 없이 주는 가치

| 주는 것 | 가이드에게 바로 좋은 점 | 우리 비용·조건 | 언제 |
|---|---|---|---|
| **무료 영문 프로필 페이지** + Licensed guide 배지 + Founding guide 배지 | 고객에게 보낼 포트폴리오. 이름·특화로 검색 노출 | 도윤 개발(프로필 템플릿 1개). 발행 승인 | 트랙 R ⑤ |

| **플래너를 업무 도구로** | 고객 견적용 일정표를 몇 분 만에 만들어 링크로 보냄 | 이미 있는 기능. "가이드 이름 표시" 기능은 나중 | 바로 |

| 매월 작은 숫자 공개 | 성장 확인 | 실제 수치만 | 트래픽이 생긴 뒤 |

## 7. 감수 글 협업 운영안

### 7-1. 감수 범위
| 감수함 | 감수하지 않음 |
|---|---|
| 장소 사실: 위치, 휴무일, 운영 시간 대(공식 페이지 링크로 확인) | 가격·환율의 실시간 정확성 보증 (글에 "확인 날짜" 표시로 대신) |
| 동선 현실성: 이동 시간, 하루 분량, 아이·노약자 무리 여부 | 의료·법률·비자 판단 |
| 교통·결제 실무: T-money, 지하철 환승, 예약 필요 여부 | 제휴 상품(eSIM·투어 등)의 품질 추천 |
| 문화·에티켓, 안전 주의 | 다른 업체·가이드 평가 |
| 현장 팁 1~3개 추가 (가이드 이름으로 인용) | 글 전체 재작성 (우리가 쓴다) |

### 7-2. 절차 (1편 기준, 영업일 5일 목표)
1. 서아·나래가 주제와 초안 확정 → 감수 요청서(체크리스트 7-1 + 초안 링크) 전달
2. 가이드 검토 (3영업일) → 항목별 "맞음 / 고침 / 모름"과 팁
3. 서아가 반영 → 가이드가 **발행본 전체**를 최종 확인 ("이대로 내 이름을 달아도 된다")
4. 감수 기록 작성(7-4) → 발행 승인 요청 → 발행
5. 발행 후 사실을 바꾸는 수정이 생기면 → 같은 가이드에게 재감수 요청

### 7-3. 표기 기준 (실제 감수한 경우에만)
| 상황 | 표기 |
|---|---|
| 가이드가 발행본 전체를 최종 확인 | `Checked by [표시 이름], licensed guide · [Month Year]` + 프로필 링크 |
| 팁만 제공, 전체 확인은 안 함 | `With tips from [표시 이름], licensed guide` (Checked 표기 금지) |
| 감수 뒤 우리가 사실을 바꾸는 수정 | 재감수 전까지 `Checked [Month Year] · Updated [Month Year] by Seoulmate` |
| 가이드 탈퇴·표기 철회 요청 | 표기 제거, 기록은 내부 보관 |
| 자동 영문화 발행 글 | 표기 없음 (감수 대상이 되면 위 절차를 따름) |

- 제휴 링크가 있는 글에는 "가이드는 글의 사실을 확인했고, 링크된 상품을 추천한 것은 아니다"는 문장을 둔다(영문 안: "Our guide checked the facts in this article. Linked products are chosen by Seoulmate."). 추천·보증 표시 기준에 걸리는지 **규리 검토**.
- 감수료를 준다면 About 또는 고지 페이지에 "Guides are paid a fee for reviewing" 같은 문장을 둘지 **규리 검토** (고지 문구 변경 = 대표 승인).

### 7-4. 감수 기록 (내부, 글마다)
글 URL / 감수자 / 요청일·완료일 / 체크 항목별 결과 / 고친 사실 수 / 추가 팁 / 최종 확인 방법(이메일 회신 등) / 표기 문구 / 감수료 지급 여부. 위치: `ops/plans/` 아래 감수 로그(운영 시작 때 만든다).

### 7-5. 감수료 (대표 결정 사항)
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 무료 | 프로필·이름 노출만 | 비용 0 | 무보수 요청은 관계를 해친다. 기한·품질 책임이 약하다 |
| B. 편당 정액 | 편당 일정 금액 | 기한·품질을 요구할 수 있다. 가이드에게 "지금 바로 받는 돈" | 비용(편당 × 10편). 원천징수 등 세무 처리 [CHECK, 세무사 T7] |
| C. 창립 혜택 연동 | 감수 참여자에게 매칭 개시 후 혜택(예: 창립 요율 기간 연장) | 현금 0 | 매칭이 열리기 전에는 가치가 없다. 요율 약속 = 고지·약관 변경 |

- **서아 추천: B.** 감수 글은 광고 트래픽(①)을 키우는 투자이고, 10편이면 총비용을 통제할 수 있다. 금액은 지후의 시장 단가 조사(감수·번역·가이드 반일 일당) 뒤 대표가 정한다. 근거 없는 금액은 여기 적지 않는다.
- 어느 안이든 돈을 쓰는 일은 대표 승인 대상이다.

## 10. 개발 고려사항 / 규정 검토 필요 사항

**개발 (도윤, 착수는 대표 승인 후)**
- 가이드 프로필 템플릿 1개 (정적 페이지, 8-1 필드). 가격·요청 버튼 영역은 기능 플래그로 꺼 둔다.
- 글 템플릿에 감수 표기 블록 (7-3의 3가지 문구). 자동 발행 파이프라인에서는 쓰지 않는다.
- 신청 폼: 외부 도구 vs 사이트 폼은 규리 검토 후 대표 결정.

**규리 검토 요청**
1. 트랙 R(감수자 모집, 가격·요청 없는 프로필 공개)이 여행업 영업 개시인지 → H6에 덧붙여 행정사에게 질문
2. "결제 없이 연결만" 시범의 위험 (H6, R11)
3. 프로필의 "차량 보유" 삭제 판단, 가이드 자가용 운송 위험 안내 필요 여부
4. 감수 표기·제휴 링크가 같이 있는 글: 추천·보증 표시 기준 해당 여부, 감수료 고지 필요 여부
5. 자격번호 비공개 + "Verified" 표시가 과장·기만에 해당하지 않는지
6. 동의서 분리 항목(8-3), 보관 기간, 외부 폼 도구 사용 시 위탁·국외 이전 고지
7. 감수료 지급 시 계약 형태(용역)·원천징수 → 세무사 T7과 함께
