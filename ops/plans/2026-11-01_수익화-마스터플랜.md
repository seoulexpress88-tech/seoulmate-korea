# Seoulmate 수익화 마스터플랜

- 작성: 메인 세션 · 2026-11-01 (대표 요청: "업계 전문가 수준의 최적 수익화 계획")
- 상위 문서: 수익 구조(CLAUDE.md, 2026-11-01), 광고·가이드 전략(ops/plans/2026-11-01_광고수익-극대화·가이드-유치-전략.md), 가이드 수수료 모델(ops/plans/2026-11-01_가이드매칭-수수료·결제-모델.md)
- **모든 금액은 가정 시나리오다. 매출이 아니다.** 요율·기준은 공개 자료(제3자 포함)라 각 공식 페이지에서 다시 확인해야 한다.

> **한 문장 요약**
> Seoulmate는 외국인 여행자의 "계획 단계"를 잡는 서비스다. 그래서 **광고는 바닥 수익, 제휴는 계획→예약 순간의 수익, 가이드 매칭은 본업 수익**으로 설계한다. 성장 단계는 날짜가 아니라 **월 방문 세션 기준(관문)**으로 넘어간다.
>
> 기여: 비전("모든 외국인이 쓰는 서비스")에는 플래너와 다국어로 다가가고, 미션("직접 즐기게")은 가이드 매칭으로 실현한다. 수익 구조 ①②③을 한 체계로 묶는다.

## 1. 전략의 뼈대: 여행자 여정마다 돈이 되는 지점

| 여정 | 여행자가 하는 일 | 우리 제품 | 수익원 | 수익 성격 |
|---|---|---|---|---|
| 꿈꾸기 | "12월 한국 어디 가지?" 검색 | 가이드 글, 축제 달력, 도시 페이지 | 디스플레이 광고 | 트래픽에 비례, 낮은 단가 |
| 계획 | 날짜·도시·동선 정하기 | **플래너**, 여행자 유형, 동선 지도 | (핵심 데이터·관계 확보) | 모든 수익의 입구 |
| 예약 | eSIM·교통·숙소·입장권 | 플래너 결과의 "이 날 필요한 것" | **제휴 수수료** | 구매 의도가 높아 단가 높음 |
| 경험 | 현지에서 가이드와 함께 | Local guides | **매칭 수수료 15%(→20%)** | 건당 수만 원, 가장 큼 |
| 공유 | 후기·추천 | 완료 예약 후기, 가이드 프로필 | (신뢰 → 검색 → 트래픽) | 순환 |

**북극성 지표(가장 중요한 숫자 하나): "월간 완성된 여행 계획 수"**
- 플래너로 일정을 만들고 복사·인쇄·가이드 요청까지 한 수다.
- 광고(체류), 제휴(예약 클릭), 매칭(요청)이 모두 이 숫자를 따라 움직인다.

## 3. 단계별 실행 (관문 = 월 세션)

### 0단계 · 기반 (지금 ~ 4주)
- 개인 도메인 + 애드센스 신청, 동의 메시지·처리방침, 제휴 고지(A-0011)
- 제휴 3종 우선 가입: 투어·입장권(Klook 등), 숙소(Agoda), eSIM. 플래너 결과·글 하단에 배치.
- 자동 영문화 복구 + **검색어 기준 주제 선정**(도시 × 계절 × 여행자 유형)
- 여행업 해당 여부 확인 → 창립 가이드 10명 모집 시작
- 측정: GA4 같은 분석 도구(동의 필요), Search Console 주간 보고

### 1단계 · 트래픽 엔진 (월 0 → 5천 세션)
- 주 7~10편, 가이드 감수 글("Checked by licensed guide") 비중 확대
- 링크를 부르는 도구: 축제 달력, 교통·eSIM 비교, 월별 날씨·옷차림
- Reddit·Pinterest 정보 답변(승인 후). 링크가 아니라 도움으로 들어간다.
- 가이드 프로필 공개, 가이드가 자기 채널로 공유
- **수동 매칭 시범**(법적 확인 범위 안에서)

### 2단계 · 수익 최적화 (월 5천 → 2.5만 세션)
- 영어권 1천 세션을 넘으면 Mediavine Journey 신청
- 뉴스레터 시작(여행 2주 전 체크리스트)
- **일본어판** 시작: 방한 상위 시장이고, 영어 다음으로 광고 단가가 괜찮은 언어(가정)
- 가이드 30명, 슈파베이스로 요청·제안 자동화
- 지자체·관광재단 1곳에 시범 협업 제안(승인 후)

### 3단계 · 확장 (월 2.5만 → 10만 세션)
- Raptive 등 프리미엄 네트워크
- 가이드 요율 20% 전환 검토(창립 가이드 12개월 이후), 가이드 Pro 구독
- 스폰서 리스팅, 중국어 번체(대만)·간체 검토(중국은 구글 광고 비중이 낮아 매칭·제휴 중심)
- 익명 트렌드 리포트

### 4단계 · 플랫폼 (월 10만 세션 ~)
- 앱(오프라인 일정, 현지 알림), 가이드 다도시 확장
- 직접 종합여행업 등록 여부 재검토: 등록하면 체험 상품 직접 판매 가능

## 4. 가정 시나리오 (월 기준, 매출 아님)

**가정**
- 1세션당 1.8페이지
- 광고 1,000뷰당: 애드센스 $6 / Journey $15 / Raptive $20
- 제휴: 1,000세션당 $25
- 가이드 요청: 세션의 0.3%, 매칭률 30%, 건당 ₩450,000, 수수료 15%
- 환율 ₩1,350/$

| 월 세션 | 광고 | 제휴 | 가이드 매칭 | 협업·스폰서 | **합계(월)** |
|---|---|---|---|---|---|
| 1만 (애드센스) | 약 ₩15만 | 약 ₩34만 | 약 ₩61만 (9건) | – | **약 ₩110만** |
| 5만 (Journey) | 약 ₩182만 | 약 ₩169만 | 약 ₩304만 (45건) | – | **약 ₩655만** |
| 20만 (Raptive) | 약 ₩972만 | 약 ₩675만 | 약 ₩1,215만 (180건) | 약 ₩500만 | **약 ₩3,360만** |

**읽는 법(전문가 관점의 핵심)**
- **광고만으로는 작다.** 월 1만 세션이면 광고는 커피값 수준이다. 광고는 "바닥"이고, 돈은 **계획 → 예약(제휴) → 경험(가이드)**에서 난다.
- 가이드 매칭이 모든 단계에서 가장 크다. 그래서 **가이드 공급을 트래픽과 동시에** 키워야 한다.
- 가장 민감한 가정은 "가이드 요청 0.3%"와 "매칭률 30%"다. 수동 매칭 시범으로 가장 먼저 실제 값을 확인한다.

## 5. 운영 지표 (월간 대시보드에 추가 제안)
| 영역 | 지표 | 목표 방향 |
|---|---|---|
| 북극성 | 완성된 여행 계획 수 | ↑ |
| 트래픽 | 세션, 영어권 비율, 검색 유입 비율, 재방문율 | ↑ |
| 광고 | 1,000뷰당 수익(RPM), 페이지/세션, 페이지 속도 | ↑ / 유지 |
| 제휴 | 클릭률, 1,000세션당 제휴 수익 | ↑ |
| 가이드 | 자격 확인 가이드 수, 감수 글 수, 요청 수, 매칭률, 건당 금액 | ↑ |
| 품질 | 환불·분쟁률, 후기 평점(실제 완료 건만) | ↓ / ↑ |

## 6. 주요 위험과 대응
| 위험 | 내용 | 대응 |
|---|---|---|
| 검색 의존 | 구글 업데이트, AI 요약(검색 결과에서 바로 답을 줘 클릭 감소) | 도구형 제품(플래너), 뉴스레터, 가이드 채널, 브랜드 검색 |
| 콘텐츠 품질 판정 | 대량·자동 생성으로 보이면 순위·애드센스 불이익 | 가이드 감수, 출처·확인 날짜, 직접 경험 표시는 실제 경험만 |
| 여행업 규제 | 가이드 매칭이 여행업으로 판단될 가능성 | 확인 전 결제 금지, 필요 시 종합여행업 등록 |
| 공급 이탈 | 가이드가 고객을 직접 데려가 수수료 회피 | 결제 보호·후기·노출 혜택을 플랫폼 안에서만 제공. 낮은 초기 요율 |
| 광고가 사용성 해침 | 광고 과다 → 이탈 → 트래픽 감소 | 플래너 무광고, 글당 광고 수 상한 |

## 8. 대표님 결정 사항
1. 개인 도메인 구매(애드센스 전제)
