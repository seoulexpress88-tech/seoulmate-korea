# 광고 수익 극대화 + 자격 가이드 유치 전략

- 작성: 메인 세션 · 2026-11-01 (대표 요청)
- 상태: **전략안**. RPM·트래픽 수치는 공개 자료 기반 가정이며 매출로 기록하지 않는다. 외부 연락·게시·가입·비용·사이트 발행은 모두 대표 승인 대상.

> **결론**
> 1) 광고 수익 = **방문자 수 × 1,000뷰당 수익(RPM)**. 지금은 방문자가 거의 없으므로, 처음 3~6개월은 **"광고 최적화"보다 "방문자 늘리기"**가 핵심이다. 이 시기 수익은 디스플레이 광고보다 **제휴 링크(eSIM, 투어, 숙소, 교통패스)**가 더 크다.
> 2) 가이드 유치는 **"트래픽을 먼저 만들고 나중에 홍보"하는 순차 방식을 추천하지 않는다.** 트래픽이 없으면 가이드에게 보여 줄 게 없어서 늦어진다. 대신 **"우리 트래픽이 없어도 가이드에게 바로 가치 있는 것"**을 먼저 주고, 가이드가 **콘텐츠와 신뢰를 만들어 트래픽을 끌어오게** 하는 **동시 진행(플라이휠)**을 추천한다.
>
> 기여: 수익 구조 ①광고(방문자·RPM)와 ②가이드 매칭(공급 확보)을 하나의 순환으로 묶는다. 미션의 "직접 즐길 수 있게"는 가이드가 실현한다.

---

## 1부. 광고 수익 극대화

### 1-1. 수익 공식과 현실
- 광고 수익 = 월 페이지뷰 ÷ 1,000 × RPM
- 여행 분야 애드센스 RPM은 공개 자료상 약 $2~15(편차 큼, 가정).
  - 예시: 월 1만 뷰 × $8 = 월 약 $80. 월 10만 뷰 × $8 = 월 약 $800.
- **영어권(미국·영국·캐나다·호주) 방문자일수록 RPM이 높다.** 우리 사이트가 영어라 유리하다.
- 프리미엄 광고 네트워크(공개 자료, 확인 필요):
  - Mediavine Journey: 영어권 월 1,000세션부터
  - Raptive: 월 25,000뷰부터
  - 애드센스보다 RPM이 보통 높다.

### 1-2. 단계별 전략
| 단계 | 기준 | 할 일 |
|---|---|---|
| 0. 준비 (이번 달) | 방문자 ~0 | 개인 도메인 연결, 애드센스 신청, 개인정보처리방침·동의 메시지, 제휴 고지 수정(A-0011), Search Console 점검 |
| 1. 트래픽 엔진 (1~3개월) | 월 1천~1만 뷰 | 콘텐츠·검색 노출 집중(아래 1-3). 광고는 글 안 1~2개만. **제휴 링크를 주 수익원으로** |
| 2. 광고 최적화 (3~6개월) | 영어권 월 1천 세션 이상 | Mediavine Journey 신청 검토, 광고 위치 테스트, 페이지 속도 유지 |
| 3. 프리미엄 (6개월~) | 월 2.5만 뷰 이상 | Raptive 등 검토, 뉴스레터(재방문)로 RPM 상승 |

### 1-3. 방문자 늘리기 (가장 중요)
1. **검색 수요가 있는 주제를 체계적으로 채운다**
   - "도시 × 계절 × 여행자 유형" 조합. 예: "Seoul in December with kids", "Busan couple itinerary 3 days", "Korea winter festivals 2026".
   - 매일 자동 영문화(현재 오류, 복구 필요)는 그대로 두고, **검색어 기준 주제 선정**을 나래가 맡는다.
2. **"쓸모 있는 도구"로 링크를 모은다**
   - 플래너, 동선 지도, 축제 달력은 다른 블로그·커뮤니티가 링크할 이유가 된다.
   - "월별 축제 달력", "T-money·교통 계산기" 같은 도구를 추가한다.
3. **신뢰 신호(구글 품질 기준)**
   - 자동 생성 느낌을 줄이고 "자격 가이드가 확인한 글" 표시를 단다(2부의 가이드 협업과 연결).
   - 글마다 확인 날짜와 출처를 둔다(이미 시행 중).
4. **커뮤니티 유입**
   - Reddit(r/koreatravel), Pinterest, Instagram에 링크 없이 도움 되는 답변을 단다(SNS는 A-0010 등 승인 후).
5. **재방문**
   - 여행 전 체크리스트 메일(뉴스레터)을 운영한다. 이메일 수집은 개인정보처리방침 변경과 승인이 필요하다.

### 1-4. RPM 높이기 (방문자 확보 후)
- 광고 위치
  - 가이드 글: 2~3번째 문단 뒤, 글 중간, 글 끝.
  - 모바일: 하단 고정 광고 1개.
  - **플래너 핵심 화면에는 넣지 않는다.** 사용성이 곧 트래픽이다.
- 자동 광고는 처음에 끄고 위치를 직접 정한다. 속도(Core Web Vitals)가 떨어지면 검색 순위도 떨어진다.
- 체류 시간: 관련 글 연결, 플래너로 이어지는 버튼.
- 제휴 링크(광고보다 1뷰당 수익이 높은 경우가 많음, 공개 자료)
  - 효과가 큰 곳: eSIM·유심, 공항철도·교통패스, 투어·입장권(Klook·Trip.com), 숙소(Agoda).
  - 플래너 결과 화면에 "이 날 필요한 것"으로 자연스럽게 배치한다.
  - 제휴 고지 문구(A-0011)를 먼저 고친다.

## 2부. 자격 가이드 유치

### 2-1. 핵심 문제: 닭과 달걀
- 가이드: "고객(트래픽)이 있어야 가입한다."
- 고객: "가이드가 있어야 요청한다."
- 순차 방식(트래픽 → 가이드)은 트래픽이 의미 있는 수준(수개월)이 될 때까지 공급이 0이다. 그 사이 경쟁사에 가이드를 뺏긴다.

### 2-2. 추천: 트래픽 없이도 가이드에게 바로 가치를 주기
| 가이드에게 주는 것 | 왜 바로 가치가 있나 | 우리에게 돌아오는 것 |
|---|---|---|
| **무료 영문 프로필 페이지** (자격 배지 포함) | 가이드 본인 고객에게 보낼 "신뢰받는 포트폴리오". 구글에 이름·전문 분야로 노출 | 공급 확보, 검색 페이지 증가 |
| **콘텐츠 협업: "Checked by licensed guide ○○"** | 가이드 이름이 글에 실려 홍보가 된다. 소정의 감수료 검토 | **글 신뢰도 상승 → 검색 순위·트래픽 → 광고 수익** |
| **플래너를 가이드 업무 도구로** | 고객에게 보낼 일정표를 플래너로 만들고 가이드 이름으로 공유 | 플래너 링크 확산, 가이드 습관화 |
| **창립 가이드 조건** | 85% 수령(첫 12개월, 이미 공지), 상단 노출, "Founding guide" 배지 | 초기 공급 |

→ 가이드 협업이 콘텐츠·신뢰를 만들고, 트래픽이 늘면 요청이 생기고, 요청이 다시 가이드를 부른다. **광고와 가이드가 서로를 키우는 구조.**

### 2-3. 누구를 먼저 데려올까
1. **새로 자격을 딴 가이드·프리랜서**: 여행사 소속이 아니라 고객이 가장 필요하다. 가장 반응이 좋다.
2. **가족·커플 전문, 사진 스냅·미식 특화 가이드**: 우리 타겟 고객과 맞는다.
3. **서울 우선 → 부산·제주**
4. 베테랑·여행사 소속 가이드는 2단계에 영입한다.

### 2-4. 어디서 만날까 (모두 외부 연락이라 승인 필요, 개인 연락처 수집 금지)
- 한국관광통역안내사협회 등 공식 단체: 제휴·공지 요청
- 관광통역안내사 교육기관·학원: 수료생 대상 안내
- 가이드 온라인 커뮤니티(공개 게시판): 운영 규칙에 맞춰 모집 글
- 대표님 인맥과 식당 네트워크: 소개
- 사이트 "For licensed guides" 섹션: 이미 있음. 가입 접수 기능은 2단계

### 2-5. 가이드 모집 실행 플랜
| 기간 | 할 일 | 목표 지표 |
|---|---|---|
| 1~2주 | 여행업 해당 여부 확인(T-0024). 모집 공고·가입 절차·프로필 양식(서아). 가입 신청은 구글 폼 등 간단한 방법(개인정보 → 승인) | 공고·절차 완성 |
| 3~4주 | 창립 가이드 10명 모집(협회·교육기관·소개). 자격 확인 → 프로필 페이지 공개(승인 후) | 창립 가이드 10명 |
| 2개월 | 가이드 감수 글 10편("Checked by licensed guide"). 가이드가 자기 채널에 프로필 공유 | 감수 글 10편, 프로필 방문 |
| 2~3개월 | **수동 매칭 시범**: 고객 요청을 받아 운영팀이 직접 가이드 2~3명에게 전달하고 결제 링크로 정산. 시스템 구축 전에 수요를 검증 | 요청 20건, 매칭 5건 |
| 3~6개월 | 수요가 확인되면 슈파베이스로 가입·요청·제안 자동화 | 가이드 30명, 월 매칭 20건 |

- 수동 매칭도 결제를 받으면 여행업 해당 여부가 똑같이 적용된다. 확인 전에는 결제 없이 연결만 시범 운영할지 규리와 정한다.

### 2-6. 트래픽 결과를 가이드 홍보에 쓰는 방법 (대표님 질문에 대한 답)
- 순차가 아니라 **"작은 숫자라도 매달 공개"**하는 방식이 좋다.
  - 예: "이번 달 가족 여행자 플래너 이용 1,200건, 가이드 요청 35건"
- 숫자는 가이드 유치의 두 번째 단계에서 쓰는 무기다. 첫 단계 무기는 프로필·협업·85%다.

## 3. 핵심 지표 (월간)
- 방문자·페이지뷰(영어권 비율), RPM, 제휴 클릭·수익
- 플래너 사용 수(여행자 유형별), 가이드 요청 수
- 등록 가이드 수(자격 확인 완료), 감수 글 수, 매칭 수·매칭 수수료

## 4. 대표님 결정이 필요한 것
1. 개인 도메인 구매·연결 (애드센스 필수 가능성 높음, 비용)
2. 제휴 링크 프로그램 가입 범위 (Klook·Trip.com·Agoda·eSIM 등)
3. 가이드 감수료 지급 여부 (돈이 드는 일)
4. 가이드 모집 외부 연락 시작 시점 (법적 확인 후 권장)
