# 결제대행사 비교: 일정 설계 상품(Custom Itinerary) 결제 준비 (T-0008)

- 작성: 도윤 (개발) · 2026-11-01 · 조회일 모두 2026-11-01
- 대상 상품: 직접 판매 D0~D4 (`ops/plans/2026-10-30_상품-구조-v2.md` 1-2). 대표 상품 **D3 Signature $249 + $25/일 (7일 $424, 약 57만 원)**
- 범위: 조사·문서만. 가입·서류 제출·외부 설정·코드 배포는 하지 않았다.
- 표기: 공식 페이지에서 확인 못 한 숫자는 **[CHECK]**. 2차 자료는 쓰지 않았다.

> **결론**
> 1) **지금 바로 열 수 있는 것은 PayPal 하나뿐**이다. 사업자 계정만 만들면 심사 없이 결제 링크를 만들 수 있고, 정적 사이트에는 링크(`<a href>`)만 붙이면 된다. 대신 실제 비용이 크다: 4.4% + $0.30에 원화로 인출할 때 환전 3%가 더 붙어 **약 7.3%** (D3 7일 $424 기준 약 $31).
> 2) 국내 PG(토스페이먼츠·KG이니시스) 해외카드는 수수료가 **비공개("별도 협의")**이고, 토스는 해외카드 계약 후 **카드사 심사만 10~14영업일**이 걸린다. 11/5 오픈에는 못 맞춘다. 대신 길게 보면 수수료를 낮출 수 있으므로 **바로 신청을 같이 넣는다**.
> 3) Stripe는 한국 사업자가 가입할 수 없다(공식 국가 목록에 한국 없음).
>
> **추천안: 1단계 PayPal 결제 링크로 11/5 오픈 → 2단계 토스페이먼츠(국내카드 + 해외카드 원화 MID) 병행 신청, 승인되면 카드 결제를 토스로 옮긴다.**
> 목표 기여: 결제가 없으면 직접 판매 매출(현실 1,210만·낙관 3,470만 원, 서아 v2)이 0원이다. 심사 없이 이번 주에 결제를 여는 유일한 길이 PayPal이다.

## 2. 사업자별 상세

### 2-1. PayPal (한국 사업자 계정)
- 계정 개설: 로그인 생성 → 은행 계좌 연결 → 판매 시작. 공식 페이지 문구: "요구 사항이 필요하지 않습니다. 비즈니스 계정만 있으면 됩니다." (가입 중 사업자등록번호 요구 여부 [CHECK])
- 수수료(2026-05-28 갱신판): 해외에서 받는 상업 거래 **4.40% + 고정 수수료(USD 0.30)**. 환전 스프레드 **3.00%**(1일 넘게 지난 환불·송금은 1.00%). 한국 은행 인출은 **15만 원 초과면 무료**, 15만 원 이하 1,500원. 차지백 $10, 분쟁 $8(대량 $16).
- 환불: 전액·부분 환불 수수료 없음. 다만 처음 받을 때 낸 수수료는 돌려받지 못한다 → 환불 규칙(v2 1-5) 손실 계산에 반영해야 함.
- 결제 링크: 상품명·가격으로 링크를 만들고 URL·QR로 공유. 웹사이트에 붙이려면 Buy 버튼 코드 붙여넣기. 설정·월 수수료 없음.
- 위험
  - **판매자 보호**: 정보·용역 상품이 PayPal 판매자 보호 대상인지 공식 원문을 열지 못했다 [CHECK]. 대상이 아니라고 가정하고, "서비스 미제공" 분쟁에 대비해 전달 기록(일정표 발송 메일, 상담 기록)을 남긴다.

### 2-2. 토스페이먼츠
- 해외카드: "대한민국이 아닌 국가에서 발급한 카드". Visa·Mastercard·JCB·UnionPay 명시. **별도 계약 필요**, 신청 후 2영업일 내 등록 + **카드사 심사 10~14영업일**.
- 통화: 기본 KRW. USD·JPY는 해외카드 다통화 별도 계약(영업 담당). **MID 하나에 통화 하나** → 원화+달러를 같이 받으려면 MID·위젯을 둘로 나눔. 공식 예시 구성: KRW MID(국내카드 + 해외카드 원화) / USD MID(해외카드 달러 + PayPal).
- PayPal 경유: 별도 계약, 서류 완비 시 2~3영업일. 수수료 4.0% + 건당 $0.3 + 환전·인출 2.5%. 호스팅사 가맹점은 PayPal 불가(우리는 독립 사이트라 해당 없음).
- 비용: 국내 신용·체크카드 일반 3.4%, 가입비 220,000원(최초 1회), 연관리비 110,000원, 모두 VAT 별도. 정산 평균 5일 이내.
- **해외카드 수수료는 수수료 안내 페이지에 없다 [CHECK]** → 신청 시 견적 요청.
- 연동: 결제위젯은 브라우저에서 스크립트 + 클라이언트 키로 띄우지만, **결제 승인은 서버에서 시크릿 키로 호출**해야 한다(공식 문서: "시크릿 키는 클라이언트, GitHub 등 외부에 노출되면 안 됩니다"). 지금 사이트는 정적 파일뿐이라 **Vercel 서버리스 함수(`api/` 폴더) + Vercel 환경변수에 시크릿 키**가 새로 필요하다 → 새 구성요소라 대표 승인 대상.
- 결제 링크형 상품의 해외카드 지원은 공식 문서에서 찾지 못함 [CHECK].
- 출처: https://www.tosspayments.com/about/fee · https://docs.tosspayments.com/guides/v2/learn/foreign-payment · https://docs.tosspayments.com/guides/v2/payment-widget/integration · https://www.tosspayments.com/contacts/paypal

### 2-5. 포트원(PortOne)
- PG가 아니라 **여러 PG를 한 번에 붙이는 연동 도구**. PG 계약(토스·이니시스 등)은 따로 해야 하고 수수료도 PG 수수료가 그대로 든다. 월 순거래액 5천만 원 미만은 무료.

- 단점: 지금 PG가 하나뿐이면 얻는 것이 적고, 서버 검증이 필요한 점은 같다.
- 결론: **지금은 쓰지 않는다.** 토스 + 이니시스를 둘 다 쓰게 되면 그때 검토.
- 출처: https://portone.io/pricing · https://portone.io/

**1단계 (11/2~11/5): PayPal 결제 링크로 직접 판매를 연다.**
- 이유: ① 심사·서류 대기 없음 → 11/5 오픈 가능한 유일한 선택지. ② 사이트에 서버를 새로 만들 필요가 없다(링크만). 비밀키도 없다. ③ 외국인 고객에게 익숙한 결제 화면. ④ 환불을 대시보드에서 바로 처리.
- 구현(도윤, 승인 후): 상품별 결제 링크 URL을 `site.json`에 넣고 상품 페이지 "Pay with PayPal" 버튼으로 연결. 일수가 바뀌는 D2~D4는 (a) 5·7·10·14일 고정 링크 + (b) 그 밖의 일수는 상담 후 **PayPal 인보이스**(카드 게스트 결제 명시됨)로 청구.
- 주의: 주문 확인은 PayPal 알림 메일로 받는다(사이트와 자동 연동 없음). 결제 후 설문 링크를 결제 완료 안내·메일에 넣는다. 실제 입금이 확인된 건만 `revenue add`로 기록.

**2단계 (신청은 바로 → 승인 시 전환): 토스페이먼츠 국내카드 + 해외카드(원화 MID).**
- 이유: ① 해외카드 Visa·Master·JCB·UnionPay, 정산 평균 5일. ② 수수료가 PayPal보다 낮을 가능성(견적으로 확인). ③ 국내 거주 외국인·한국 카드 고객도 받을 수 있음. ④ 가이드 매칭(지급대행) 후보로 검토 중인 회사와 같아 계약을 한 곳으로 모을 수 있음.
- 대가: 가입비 22만 + 연관리비 11만(VAT 별도), Vercel 서버리스 함수 1개(결제 승인) 추가 → 새 구성요소라 별도 승인.
- **Amex 비중이 크다고 판단되면** 이니시스를 대안으로 견적 비교(이니시스는 Amex·Diners 명시).

**하지 않을 것**: Stripe(불가), 나이스페이(해외카드 미확인·보증보험 부담), 포트원(PG 하나일 때 이점 적음), 고객 대금을 개인 계좌로 받기.

## 5. 대표님이 직접 하실 일

PG 심사에서는 보통 사이트에 상품·가격, 이용약관, 환불 규정, 사업자 정보가 보여야 한다(각 사 심사 기준 원문은 이번에 확인 못 함 [CHECK]). 이 페이지들은 규리 검토 + 대표 승인 후 도윤이 만든다.
