# 가이드 매칭 법적 확인: 전문가 상담 질문 목록 + 종합여행업 등록 체크리스트

- 작성: 규리 (컴플라이언스)
- 일시: 2026-11-01 14:27
- 관련 작업: T-0024

[규리 · 컴플라이언스 검토] 가이드 매칭 법적 확인 준비 (T-0024)
결론: 수정 후 가능 — 결제는 행정사 답(H1·H2)을 받기 전까지 열지 않는다

요약
- 행정사용 질문 25개(여행업·통신판매중개·PG)와 세무사용 질문 13개를 만들었다. 각 질문에 "왜 묻는지 / 답에 따라 바뀌는 것"을 적었다. 상담 순서는 행정사 → 세무사다. 세금 처리는 "우리가 계약 당사자인지 중개자인지"에 따라 달라지기 때문이다.
- 새로 찾은 높은 위험: 지금 안(구조 A: 가이드가 판매자, 우리는 중개)에서는 **가이드 개인이 무등록 여행업자가 될 수 있다**. 그렇다는 답이 나오면 우리가 종합여행업을 등록하고 직접 판매(구조 B)로 가야 한다. 구조 B는 부가세 영세율(시행령 제33조 ②7) 가능성이 있어 세금 면에서도 유리할 수 있다.
- 종합여행업 등록 체크리스트를 정리했다(요건·서류·순서·비용). 처리기간·수수료·보증보험료·등록면허세는 공식 출처로 확인하지 못해 [CHECK]로 표시했다. 결제 오픈은 12월 초~중순이 현실적이다(추정).

위험
- R11 구조 A에서 가이드 개인의 무등록 여행업 해당 가능성 · 높음 · 관광진흥법 제3조 ①1, 제4조 ①, 제82조 1호
- R12 원천징수 의무자 불명확 · 보통 · 세무사 확인
- R13 VAT 포함 여부가 정해지지 않은 가격 표시 · 보통 · 부가세법 시행령 제33조 ②1(여행보조 서비스업 제외)·②7
- R14 전자금융거래법 개정(2026.12.17 시행, 시행령 미확정) · 보통

수정안: 지금은 없음(문서 작업만 함). 결제·가이드 요청 기능은 지금 상태(결제 비활성)를 유지한다.

대표 결정 필요
1. 행정사 → 세무사 상담 예약(A-0005 범위)
2. 해석이 갈리면 문체부·구청에 서면으로 질의할지(외부 기관 문의라 승인 필요)
3. 등록 주체(개인/법인)와 사무실(식당 겸용/별도): 상담 후 결정
4. H6에서 "영업 개시"라는 답이 나오면 사이트의 가이드 요청 기능을 일시 중단할지

전문가 확인 필요: 질문 목록 문서의 H1~H16, E1~E6, F1~F4, T1~T13
