# Seoulmate: 외국인 대상 한국 여행 웹사이트

외국인 여행자가 일정과 관심사를 넣으면 날짜별 여행 일정을 짜 주는 **트립 플래너**와, 매일 올라오는 영문 **여행 가이드 블로그**로 이루어진 웹사이트입니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `content/posts/` | 웹사이트에 올라간 영문 글 원본입니다. 직접 고치면 다음 발행 때 반영돼요. 글을 내리려면 맨 위 `"draft": false`를 `true`로 바꾸세요. |
| `static/` | 디자인(`style.css`), 트립 플래너(`planner.js`), 아이콘 |
| `site.json` | 사이트 이름, 주소, 제휴 링크, 연락처 이메일 |
| `build.py` | 글을 가져와 사이트를 만들고 GitHub에 올리는 스크립트 |
| `public/` | 완성된 사이트입니다. Vercel이 이 폴더를 그대로 띄워요. 직접 고치지 마세요. |
| `docs/business-model.md` | 수익 모델 정리 |

## 매일 자동으로 돌아가는 흐름

| 시간 | 하는 일 |
|---|---|
| 08:37 | 영문 글 작성 작업이 `해외 블로그 수익화\posts\날짜\`에 새 글을 저장해요 (기존 흐름) |
| 10:00 | 기존 작업이 같은 글을 Blogger 임시저장으로 올려요 (기존 흐름) |
| **10:30** | **`Seoulmate_Publish` 작업이 새 글을 이 사이트로 가져와 발행해요** |

10:30 작업이 하는 일:
1. `해외 블로그 수익화\posts`에서 아직 가져오지 않은 글을 `content/posts`로 복사
2. 발행하면 안 되는 표시를 정리: `[PHOTO]`·`[YOUR NOTE]` 문단 삭제, `[CHECK]` 표시 삭제 후 글 위에 "정보 확인일" 안내 추가, `[AFFILIATE]`는 `site.json`에 링크가 있으면 버튼으로 바꾸고 없으면 숨김
3. 사이트 전체 다시 만들기 (글 목록, 도시별 페이지, sitemap.xml, RSS)
4. GitHub에 올리면 Vercel이 1~2분 안에 사이트를 갱신

컴퓨터가 꺼져 있으면 그날은 실행되지 않지만, 다음 실행 때 밀린 글을 모두 가져와요. 기록은 `logs/publish.log`에 남아요.

## 제휴 링크 넣기 (Klook 등 승인 후)

`site.json`의 `affiliate_links`에 글 속 `[AFFILIATE: ...]` 문구를 그대로 키로 넣으면, 지난 글까지 모두 버튼으로 바뀌고 글 하단에 제휴 고지 문구가 자동으로 붙어요.

```json
"affiliate_links": {
  "Klook — KTX ticket / KORAIL PASS": "https://www.klook.com/...내 제휴 링크..."
}
```
